# ADR-0003

## Context

The `YamlNode` model could be generalized to represent any hierarchical document, regardless of its source format.

## Decision

Keep the name `YamlNode` as long as YAML remains the only supported input format.

## Consequences

If a second input format (such as JSON or XML) is introduced, revisit this decision and consider replacing `YamlNode` with a more generic type, such as `Node` or `DocumentNode`.
